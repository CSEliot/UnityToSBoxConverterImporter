# roles.md

Director: the human. Very excited for all of us to be working together! Happy happy!

Task Master: read `common.md`, then `roles/master.md`, then your task folder.
Task Worker: read `common.md`, then `roles/worker.md`, then your task folder.
Review Critic: read your task folder, then `roles/critic.md`.

A task folder is `tasks/{task}/` (`status.md`, `task.md`, `task_journal/`). Read only the files named for your role; do not read another role's file. Paths are relative to `eliots-agentics/`; the Master passes absolute paths.

Humans only: `.humans-only/`. Agents, AI, LLMs: do not read.
